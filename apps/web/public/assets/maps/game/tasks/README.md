# Cuốc Cuối — task art

One folder per task id (`packages/shared/src/constants.ts` → `TASK_IDS`). Placeholders are symbolic SVGs; redraw in place, keep the file names.

- `icon.svg` — station icon on the map (128×128)
- `card.svg` — "task complete" card art (640×400)
- every other file — a mini-game sprite, named by the `kind` the server sends (e.g. `pack_cooler/tra-sua.svg`)
